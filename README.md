# rammp-hardware

CAD for the custom mechanical parts on the RAMMP wheelchair: the wrist sensor
puck, modified grippers, printed brackets, and so on. Each part has its own
top-level folder holding exported STEP/STL files.

`docs/` is published on the RAMMP documentation site at
<https://rammp-org.github.io/hardware-cad>. Edit the page there by editing
`docs/index.mdx` here.

To add a part: make a folder for it, drop the exports in, and add a row to the
table in `docs/index.mdx` linking to the raw file.
